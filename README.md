# GEP1316 Kodlama Okuryazarlığı — Kişisel Portfolyo

**Canlı Site (GitHub Pages):** [https://ceydakzlc.github.io/gep1316-portfolyo/](https://ceydakzlc.github.io/gep1316-portfolyo/)

* **Öğrenci:** Ceyda Kızılca (Bahçeşehir Üniversitesi — Çizgi Film ve Animasyon)

## Site Yapısı
1. **Ana Sayfa (`index.html`):** Kısa tanıtım, illüstrasyon avatar, gezinti menüsü ve sayfa yönlendirmeleri.
2. **Hakkımda (`hakkimda.html`):** Eğitim bilgileri, ilgi alanları ve *"Kodlama ve Yapay Zekânın Mesleğimdeki Yeri"* yazısı.
3. **Projeler (`projeler.html`):** Ödev 1 (`Ogrenci_Not_Hesaplayici`), portfolyo projesi ve dönem çalışmaları kartları (görsel, açıklama, GitHub bağlantısı, *"Ne Öğrendim?"* özeti, arama/filtreleme ve canlı not simülasyonu).
4. **İletişim (`iletisim.html`):** Kişisel telefon veya adres bilgisi talep etmeyen doğrulamalı iletişim formu, aydınlatma metni ve GitHub / üniversite bağlantıları.

## Gizlilik ve Erişilebilirlik
* Sitede hiçbir üçüncü taraf izleyici (analytics), reklam çerezi veya harici takip betiği kullanılmamaktadır.
* Karanlık/Aydınlık tema tercihi yalnızca kullanıcının kendi tarayıcısında (`localStorage`) saklanır.
* Semantik HTML5 etiketleri, klavye odak halkaları, yüksek renk kontrastı ve ekran okuyucu uyumlu etiketler uygulanmıştır.
